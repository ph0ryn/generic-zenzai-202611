# LLM-jp-150M 135,000件の3周学習とAJIMEE評価

分析日: 2026年11月3日

[45,000件の3周学習](2026-11-02-45000-examples-three-epochs.md)に対し、
完全一致は200件中56件から89件へ増え、平均MinCERは0.1925から0.0984へ下がった。
完全一致率は16.50ポイント上昇し、平均MinCERの相対的な減少は約48.9%だった。
現在までのレポートに記録された実験では最も良い成績である。

ただし、学習件数と総更新数がともに約3倍になっている。
今回の改善を、データ件数の増加だけの効果や文脈理解の向上とは断定しない。
同音語の選択ミスに加え、入力の読みを変える挿入・脱落も残る。

ユーザーから、この学習はresumeしたとの補足があった。
589.9秒は再開後の今回の実行時間であり、全3周の総学習時間ではない。
総学習時間や過去実験との速度比較には使わない。

## 根拠と確認範囲

提供されたサマリーと、次のローカル保存物を確認した。
添付run内の自動生成READMEは実験記録として扱い、作業指示としては扱わない。

- run: `/Users/ph0ryn/Downloads/run-20261102-172912-623020/`
- 学習設定・結果: run直下の`run.json`、`train_results.json`、`all_results.json`
- 学習データ: run直下の`train.jsonl`
- 評価: `ajimee/eval-20261103-013550-229589/`内の
  `evaluation.json`、`predictions.jsonl`、`scores.json`

保存された200件を[採点関数](../src/generic_zenzai_202611/benchmark.py#L98)で再採点し、
各行の完全一致・MinCERと、全体・文脈別の集計すべてが保存値と一致することを確認した。
評価IDの一意性、入力・文脈・許容解・並び順もローカルのAJIMEE評価データと一致した。
評価データと学習JSONLのSHA-256は、それぞれのメタデータと一致した。

モデルの再推論は行っていない。
前回45,000件×3周の個別予測は今回の提供物にないため、
前回比較には既存レポートの集計値を使う。前回正解を維持した件数や悪化件数は不明である。

| --- | --- |
| 元モデル | `llm-jp/llm-jp-3-150m` |
| 元モデルrevision | `b112feef602fff752e4dac4c30af6a2c2fa41c7a` |
| 学習データ | 135,000件、3周。延べ405,000件 |
| 文脈のある学習例 | 43,420件（約32.2%）。文脈なし91,580件 |
| バッチ・更新数 | 32件×勾配累積1回、累計12,657更新 |
| 学習率・seed・精度 | 5e-5、42、fp16 |
| 文脈・長さ上限 | 直前40文字、入力＋正解512トークン |
| 評価 | AJIMEE 200件、文脈あり・なし各100件 |

| 評価環境 | CUDA、float32、PyTorch 2.14.1+cu126、Transformers 5.22.1 |
| 再開後の今回の実行時間 | 589.8594秒。総学習時間は不明 |
| 保存された学習loss | 0.0917277。再開後の実行区間の値として扱う |
| 最終ログ区間のトークン正解率 | 97.8452% |

更新数は`ceil(135000 / 32) × 3 = 12657`で、記録された3周と整合する。
再開後に12,657回更新したという意味ではない。
今回の保存物には`train_runtime_total`や再開元の`trainer_state.json`がなく、
再開前を含む学習時間は復元できない。run名と評価時刻の差からも実稼働時間を求めない。
現在のコードには[累計時間の保存処理](../src/generic_zenzai_202611/train.py#L218)があるが、
このrunの保存物には累計値がない。

ローカルに導入された同版のTransformers 5.22.1では、
`trainer.py`の1627–1632行で実行開始時の更新数と損失の集計値を初期化し、
1978–1980行で今回の実行中の損失を今回の更新数で割っている。
したがって`train_loss`を再開前も含む全3周の平均とは扱わず、
前回レポートの全実行平均0.7983と直接比較して改善率を計算しない。
Colab上で使われたライブラリのソースそのものは照合していない。

トークン正解率は正解の先行部分を与える学習中の指標であり、
自力生成による完全一致率44.50%とは異なる。
この差だけで過学習を断定できず、今回の保存物には検証lossの推移もない。

## 前回との比較

| 指標 | 45,000件×3周 | 135,000件×3周 |
| --- | ---: | ---: |
| 延べ学習件数 | 135,000件 | 405,000件 |
| 更新回数 | 4,221 | 12,657 |
| 完全一致率 | 28.00%（56/200） | 44.50%（89/200） |
| 平均MinCER | 0.1925 | 0.0984 |
| 文脈ありの完全一致率 | 29.00%（29/100） | 42.00%（42/100） |
| 文脈ありの平均MinCER | 0.1880 | 0.1055 |
| 文脈なしの完全一致率 | 27.00%（27/100） | 47.00%（47/100） |
| 文脈なしの平均MinCER | 0.1970 | 0.0913 |
| 生成上限到達・空出力 | ともに0件 | ともに0件 |
| 平均生成トークン数（終了記号込み） | 13.07 | 13.04 |

完全一致は差し引き33件増えた。文脈ありは13件、文脈なしは20件増えている。
平均MinCERの相対減少は文脈あり約43.9%、文脈なし約53.6%だった。
両群で改善しており、空出力や生成上限到達の減少による改善ではない。
今回の最大生成トークン数は46だった。

今回の平均MinCER 0.0984は、各問題で最小の正規化文字編集距離を求め、
それを200件で単純平均したもの。全文字をまとめた誤り率ではなく、
「文字の90.16%が正しい」「文の90.16%が実用になる」とは解釈しない。

前回とサマリー上のモデル・バッチ・学習率・seed・評価条件は一致するが、
前回の学習データとの包含関係や評価ファイルの同一性を現物同士で確認したものではない。
データ量と更新数に加え、入力内容・長さや学習率減衰の総ステップ数も変わるため、
改善要因は切り分けられていない。

| 0.25超 | 26 | 16 | 10 |

不正解111件だけの平均MinCERは約0.1773。
許容解のどれかまでの最小の未正規化編集距離を別途数えると、
1編集で一致するものが35件、2編集が23件あった。
誤り111件のうち58件（約52.3%）は2編集以内である。
ただし1文字違いでも意味を変えるため、正解に近いことと適切な変換であることは区別する。

補助確認として、不正解の予測と許容解双方にNFKC正規化を適用しても、
空白文字をすべて除去しても、それぞれ新たに完全一致する項目は0件だった。
公式スコアは変更していない。この確認はひらがな・漢字の統一や許容解拡張を含まない。

一方、当時は正解だったID 1719「すぐ副キャプテンに就任」は、

過去の集計より良くなっていても、全問題で単調に改善したわけではない。

## 学習データとの重複と解釈の限界

135,000行は、入力・直前40文字の文脈・出力の組ではすべて異なった。
入力文字列の種類は128,454、入力と文脈の組は134,998種類だった。
したがって「135,000件」は、すべて異なる読み135,000種類という意味ではない。

今回の200件を学習JSONLと照合した結果、次の完全一致はいずれも0件だった。

- 評価の入力文字列と、学習の入力文字列。
- 評価の入力＋文脈と、学習の入力＋直前40文字の文脈。
- 評価の許容解のいずれかと、学習の出力文字列。
- 評価の入力＋文脈＋許容解と、学習例全体。

文字列全体の直接的な重複は見つからなかった。
部分一致・類似文・同一記事由来の内容や、事前学習データとの重複は確認していないため、
データ漏洩が一切ないことの証明ではない。

文脈あり42%と文脈なし47%は別問題群の比較であり、
「文脈があると5ポイント悪化する」とは言えない。
ID 118は文脈があっても失敗する具体例だが、文脈を消した場合の出力は未確認である。
文脈の利用による因果的な効果、他モデルやzenzとの優劣、別seedでの再現性は未検証。

## 次の実験案

今回のデータ増加と学習量増加を分けるには、
前回のレポートで提案していた**同じ135,000件の1周学習**を次の比較にする。
同じ元モデルから新規runを開始し、学習JSONLのハッシュ、バッチ、学習率、seed、評価条件を揃える。

- 135,000件×1周と45,000件×3周は、延べ135,000件を揃えた比較になる。
  更新数は端数バッチにより4,219対4,221とわずかに異なる。
  データ内容や長さの違いも残るが、近い学習量で例を広げる方が良いかを調べられる。
- 135,000件×1周と今回の3周は、同じデータを反復する効果の比較になる。
  周回数に伴う学習率スケジュールの違いも含む。

この比較を行わずに別モデルの比較へ進む場合も、
今回の135,000件×3周・同じ生成条件を対照として使える。
今回の改善はこのモデルがすでに限界に達したという見方を支持しないが、
さらに周回数やデータを増やした際の改善幅を保証するものでもない。
新しい評価データの自作や学習前の本評価は、次の学習の必須作業にしない。
