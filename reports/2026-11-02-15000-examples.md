# LLM-jp-150M 15,000件の1周・3周学習とAJIMEE評価

実施日: 2026年11月2日

[5,000件の3周学習](2026-11-02-three-epochs.md)に続き、
学習データを15,000件に増やして、1周と3周の結果を比較した。
完全一致は200件中12件から26件へ増え、平均MinCERは0.4724から0.3389に下がった。
平均MinCERの相対的な減少は約28.3%で、生成上限到達も2件から0件になった。
今回の200件では、15,000件を3周学習することで変換成績が改善した。

本レポートは共有された2回の実験サマリーに基づく。
Driveの個別予測の確認や再採点は行っていない。

## 実験条件

| 項目 | 条件 |
| --- | --- |
| 元モデル | LLM-jp-3-150m |
| 学習データ | 15,000件 |
| 周回数 | 1 epochと3 epochs |
| 入力 | 直前40文字までの文脈と、カタカナの読み |
| バッチ | 2件 × 勾配累積16回。実効32件 |
| 学習率・seed | 5e-5、seed 42 |
| 学習時の長さ上限 | 入力と正解を合わせて512トークン |
| 学習時の計算精度 | fp16 |
| 評価 | AJIMEEの200件。文脈あり・なし各100件 |
| 生成条件 | fp32、greedy、生成上限64トークン |
| 評価時の長さ上限 | 入力と生成を合わせて512トークン |
| 実行環境 | Google Colab / CUDA、PyTorch 2.14.1+cu126、Transformers 5.22.1 |

サマリー上の元モデル・データ件数・学習率・バッチ・seed・評価条件は両実験で一致する。
3周は合計の周回数であり、1周学習済みモデルにさらに3周を追加する実験ではない。
データの内容やモデルの同一性を、保存ファイルどうしで照合したものではない。

採点では、許容解との完全一致率と平均MinCERを使う。
MinCERは低いほど良く、各項目で許容解ごとの文字編集距離を正解文字数で割り、
その最小値を取る。平均MinCERは、それを全項目で単純平均した値である。
空白除去や表記の正規化は行わない。

## 学習の実行結果

| 指標 | 1周 | 3周 |
| --- | ---: | ---: |
| 延べ学習件数 | 15,000件 | 45,000件 |
| 更新回数 | 469 | 1,407 |
| 学習時間 | 954.8秒（約15分55秒） | 2,980.3秒（約49分40秒） |
| 学習loss | 2.2073 | 1.0433 |
| 最終ログ区間のトークン正解率 | 73.03% | 98.24% |

3周の学習時間は1周の約3.12倍だった。
時間は学習処理の記録値であり、環境構築・モデル取得・評価の時間を含めない。

学習lossは下がり、最終ログ区間のトークン正解率も上がった。
この正解率は、正解文のそれまでの部分を与えて次のトークンを当てる指標であり、
文章全体を自力で生成する評価時の完全一致率とは異なる。
98.24%とAJIMEEの13.00%を直接比較して過学習とは判断できない。
今回の比較では、学習指標だけでなくAJIMEEの成績も改善した。

## AJIMEEの1周・3周比較

| 区分 | 件数 | 完全一致: 1周 → 3周 | 平均MinCER: 1周 → 3周 | 生成上限到達: 1周 → 3周 |
| --- | ---: | ---: | ---: | ---: |
| 全体 | 200 | 6.00%（12件） → 13.00%（26件） | 0.4724 → 0.3389 | 2 → 0 |
| 文脈あり | 100 | 7.00%（7件） → 11.00%（11件） | 0.4484 → 0.3384 | 1 → 0 |
| 文脈なし | 100 | 5.00%（5件） → 15.00%（15件） | 0.4963 → 0.3395 | 1 → 0 |

完全一致率は7.00ポイント上昇し、正解数は差し引き14件増えた。
個別予測を比較していないため、1周で正解だった項目を何件維持したか、
新たに正解になった項目が何件あるかは分からない。

平均MinCERは0.1335下がり、1周に対して約28.3%減少した。
文脈ありでは約24.5%、文脈なしでは約31.6%減少している。
両方の問題群で、完全一致率と平均MinCERが改善した。
これは文字誤りの指標の変化であり、完全一致率が28.3ポイント上がったという意味ではない。

| 生成に関する指標 | 1周 | 3周 |
| --- | ---: | ---: |
| 空出力 | 0件 | 0件 |
| 生成上限到達 | 2件 | 0件 |
| 平均生成トークン数 | 13.96 | 13.38 |

生成トークン数には終了記号を含む。
3周では全200件が終了記号を出して停止し、空出力もなかった。
ただし、上限到達が0件でも、上限より短い反復や読みから外れる誤変換の有無までは分からない。

## 5,000件の実験からの変化

| 学習条件 | 更新回数 | 学習時間 | 完全一致率 | 平均MinCER | 生成上限 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 5,000件 × 3周 | 471 | 972.4秒 | 5.50% | 0.5889 | 128 |
| 15,000件 × 1周 | 469 | 954.8秒 | 6.00% | 0.4724 | 64 |
| 15,000件 × 3周 | 1,407 | 2,980.3秒 | 13.00% | 0.3389 | 64 |

5,000件×3周と15,000件×1周は、延べ学習件数がともに15,000件で、
更新回数と学習時間も近い。
後者では完全一致数は11件から12件への小幅な増加だったが、
平均MinCERは約19.8%下がった。
同じ例を繰り返すだけでなく、学習する例を増やす方針が有望という結果だった。
ただし生成上限も128から64に変わっており、改善をデータ件数だけに帰属させる比較ではない。

今回の15,000件の1周・3周比較では、生成上限は64で一致している。
データを増やした後も、3周まで学習量を増やすことで成績がさらに改善した。
学習量に伴って学習率の減衰に使う更新回数も増えるため、
データの反復だけを独立に変えた比較ではない。

## 解釈の範囲

今回の結果は、LLM-jp-150Mへのかな漢字変換の追加学習が進むと、
この200件でのモデル単体の変換成績が改善したことを示す。
完全一致は26件で、残る174件は許容解と一致していない。
3周が最適であること、さらに周回数を増やせば改善が続くこと、
他の事前学習済みモデルより優れていることまでは判断できない。

文脈あり100件と文脈なし100件は別の問題群である。
11.00%対15.00%という差から、文脈が逆効果だったとは言えない。
両群の成績が改善したことも、文脈理解の向上そのものを実証するものではない。

個別問題の改善・悪化、誤変換の種類、学習データと評価データの重複、
別seedでの再現性は今回確認していない。
辞書・探索・読みの制約を組み合わせたIME全体の評価も対象外。

## 次の実験案

元モデルから45,000件を1周学習し、今回の15,000件×3周と比較する。
内訳は文脈あり22,500件、文脈なし22,500件とする。
モデル・学習率・バッチ・seedを揃え、評価は同じAJIMEEの200件、生成上限64とする。

延べ学習件数を45,000件に揃え、同じ例を3回見る場合と、
より多くの例を1回ずつ見る場合の違いを調べる。
データの長さや内容も変わるため、延べ件数が同じでも厳密に同じ計算量にはならない。
実際の更新回数・学習時間と、完全一致率・平均MinCER・生成上限到達件数を比較する。

45,000件の学習・評価結果は、このレポートには含まれない。
