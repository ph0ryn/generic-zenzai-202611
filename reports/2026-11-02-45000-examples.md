# LLM-jp-150M 45,000件の1周学習とAJIMEE評価

実施日: 2026年11月2日

[15,000件の3周学習](2026-11-02-15000-examples.md)と、45,000件の1周学習を比較した。
延べ学習件数と更新回数を揃えた今回の比較では、学習データを増やした方が良かった。
完全一致は200件中26件から38件へ増え、平均MinCERは0.3389から0.2372へ約30.0%下がった。
学習時間の増加は約1.9%で、両方の実験とも生成上限到達・空出力は0件だった。

本レポートは共有された実験サマリーと前回のレポートに基づく。
Driveの個別予測の確認や再採点は行っていない。

## 実験条件

| 項目 | 条件 |
| --- | --- |
| 元モデル | LLM-jp-3-150m |
| 学習データ・周回数 | 45,000件、1 epoch |
| 入力 | 直前40文字までの文脈と、カタカナの読み |
| バッチ | 2件 × 勾配累積16回。実効32件 |
| 学習率・seed | 5e-5、seed 42 |
| 学習時の長さ上限・精度 | 入力と正解を合わせて512トークン、fp16 |
| 評価 | AJIMEEの200件。文脈あり・なし各100件 |
| 生成条件 | fp32、greedy、生成上限64トークン |
| 評価時の長さ上限 | 入力と生成を合わせて512トークン |
| 実行環境 | Google Colab / CUDA、PyTorch 2.14.1+cu126、Transformers 5.22.1 |

サマリー上では、前回と元モデル・学習率・バッチ・seed・評価条件が一致する。
採点は許容解との完全一致とMinCERで、空白除去や表記の正規化は行わない。
学習データの重複や両実験のデータの包含関係は、サマリーだけでは確認していない。

## 学習量と学習指標の比較

| 指標 | 15,000件 × 3周 | 45,000件 × 1周 |
| --- | ---: | ---: |
| 延べ学習件数 | 45,000件 | 45,000件 |
| 更新回数 | 1,407 | 1,407 |
| 学習時間 | 2,980.3秒（約49分40秒） | 3,036.8秒（約50分37秒） |
| 学習loss | 1.0433 | 1.6343 |
| 最終ログ区間のトークン正解率 | 98.24% | 81.48% |

学習時間の差は56.5秒、約1.9%だった。
更新回数は同じで、実測時間も近い条件で比較できた。
ただし入力の長さや内容まで同じではないため、計算量が厳密に等しいとは扱わない。
時間は学習処理の記録値であり、環境構築・モデル取得・評価の時間を含めない。

学習lossとトークン正解率は、同じ15,000件を3回学習した方が良かった。
一方、AJIMEEの成績は45,000件を1回学習した方が良かった。
学習データ上の指標だけでは、評価時の良さを選べないことがこの比較にも表れている。

トークン正解率は、正解文のそれまでの部分を与えて次のトークンを当てる指標である。
文章全体を自力で生成する評価時の完全一致率とは異なり、
今回の81.48%と19.00%の差から過学習とは判断できない。

## AJIMEEの比較

| 区分 | 件数 | 完全一致: 前回 → 今回 | 平均MinCER: 前回 → 今回 |
| --- | ---: | ---: | ---: |
| 全体 | 200 | 13.00%（26件） → 19.00%（38件） | 0.3389 → 0.2372 |
| 文脈あり | 100 | 11.00%（11件） → 17.00%（17件） | 0.3384 → 0.2268 |
| 文脈なし | 100 | 15.00%（15件） → 21.00%（21件） | 0.3395 → 0.2477 |

完全一致率は6.00ポイント上昇し、正解数は差し引き12件増えた。
文脈あり・なしの両群で、正解数はそれぞれ6件増えた。
個別予測を比較していないため、前回の正解を何件維持したか、
新たに正解になった項目が何件あるかは分からない。

平均MinCERは0.1017下がり、前回に対して約30.0%減少した。
文脈ありでは約33.0%、文脈なしでは約27.0%減少している。
両方の問題群で、完全一致率と平均MinCERが改善した。

| 生成に関する指標 | 前回 | 今回 |
| --- | ---: | ---: |
| 生成上限到達 | 0件 | 0件 |
| 空出力 | 0件 | 0件 |
| 平均生成トークン数 | 13.38 | 13.19 |

生成トークン数には終了記号を含む。
両方とも全200件が終了記号を出して停止しており、
今回の差は生成上限到達や空出力の件数が減ったことによるものではない。

## 解釈の範囲

同じ例を3回学習するよりも、学習する例を増やして1回学習する方が、
今回の更新回数・時間の近い条件では良い結果になった。
ただし、データの内容も変わるため、多様性や件数のどちらが効いたかを独立に示す比較ではない。
完全一致は38件で、残る162件は許容解と一致していない。

文脈あり100件と文脈なし100件は別の問題群である。
17.00%対21.00%という差から、文脈の効果は判断できない。
今回の改善だけで、文脈理解の向上や他モデルに対する優位性を実証したものでもない。

個別問題の改善・悪化、誤変換の種類、学習データと評価データの重複、
別seedでの再現性は未確認。辞書・探索・読みの制約を組み合わせたIME全体の評価も対象外。

## 次の実験案

元モデルから45,000件を3周学習し、今回の1周と比較する。
評価条件は維持し、完全一致率・平均MinCER・生成上限到達件数の変化を見る。
15,000件では3周まで増やす効果があったが、45,000件でも同様に改善するかは未確認。

今回と同じ速度なら、学習時間を単純に3倍した見積もりは約2時間32分になる。
これは実測値ではなく、環境や設定の変化によって所要時間は変わる。
45,000件の3周学習の結果は、このレポートには含まれない。
